# Galaga

A Galaga clone built with SDL2 and C.

## Building

### Install Dependencies

```bash
make install
```

### Build

```bash
make
```

### Run

```bash
./galaga
```

## Controls

- ESC: Quit

## Game Info

- Resolution: 288x224 (original Galaga resolution)
- Window scales to 90% of screen height
- Aspect ratio maintained
